# 사용자 과업지 — 합성 데모

실제 뉴스·계좌·투자판단 도구 검수가 아닙니다. 도움받은 단계와 막힌 단계를 그대로 기록하세요. 진행자는 정답 기준을 먼저 보여주지 않습니다.

1. 대만 동쪽 지진 사건을 찾아 위치와 확인 가능한 내용을 설명하세요.
2. 홍해 사건에서 운항 변화와 공급 중단이 같은 뜻인지 설명하고 보완 자료를 찾아보세요.
3. 자료 없음·오래됨·읽기 실패 화면이 각각 무엇을 의미하는지 설명하세요.
4. SOXL을 검색해 Research로 갔다가 같은 사건으로 돌아오세요.
5. 개선안에서 사건을 저장하고 다른 사건 선택 후 저장 기록을 다시 여세요. reload 후 내보내세요.
6. 과거 한 시간의 실제 자료를 비교할 수 있는지, 실행에 필요한 계정·키·네트워크가 무엇인지 설명하세요.
